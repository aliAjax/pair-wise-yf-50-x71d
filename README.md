# pair-wise-yf-50 灾后需求评估与任务分派离线前端

源提示词摘要：评估员在弱网环境离线记录家庭需求、特殊照护和现场说明，团队负责人合并重复记录、分派复核任务并追踪进展；多人修改同一记录时提供字段级冲突展示，不静默覆盖。

## 技术栈

Nuxt3、TypeScript、Naive UI、Pinia、Nuxt路由、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62015

## 回站合并批（可续作）

离线期间各平板独立改户档，回站后不再整包覆盖，而是生成**合并批**逐字段对齐：

- **字段级三方对齐**：按「本机值 / 远端基准值 / 远端新值」逐字段比对。仅一边改过 → 应用该边；两边都改过 → 保留两个来源值并生成待处理冲突，人工定案前不覆盖。
- **未定案不推进状态**：存在待处理字段冲突的家庭标记「未定案」，分派任务、完成任务都不会推进其家庭状态。
- **重复登记合并**：字段对齐合并，两边都改过的字段保留两个来源值；复核任务与待同步操作一并转移到保留记录，同名任务合并时进度不倒退；后续合并批中指向已消失记录的操作经别名表改投保留记录。
- **失败可恢复**：合并批执行前自动快照，中断后保留已接收流水，可「续作重试」（已接收字段凭操作流水跳过、不重复写入）或「恢复原包」回滚后整体重试。

说明：本应用为离线优先的现场应用，状态保存在设备 localStorage，已关闭 SSR 以纯客户端渲染运行（naive-ui/css-render 依赖 DOM）。
